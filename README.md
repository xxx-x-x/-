# 垃圾时装周：干员行动

零依赖 Canvas 搜打撤小游戏。开局可选威龙、红狼、蜂医，红狼拥有可实际使用的三项技能。

## 美术资源

游戏已接入 `assets/generated` 中的俯视仓库地图与透明序列帧素材：清洁队 8 帧行走动画、枪口火焰、子弹命中、爆炸和战术烟雾。资源会在页面启动时异步预载；加载完成前自动使用原有 Canvas 图形降级绘制，因此直接打开页面或网络较慢时也不会阻塞玩法。

- 地图按 3:2 比例映射到完整的 `1800 × 1200` 世界坐标。
- 动画表统一按从左到右、从上到下的顺序播放。
- `assets/generated/manifest.json` 记录每张图的帧数、网格、透明度和建议帧率。
- `assets/generated/originals` 保留生成原图；游戏使用外层经过单元格归一化的版本。

## 启动

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8766/`。也可直接双击 `index.html`，游戏无需安装依赖。

手机浏览器建议竖屏游玩。页面已适配刘海屏安全区与动态视口高度，不需要手动缩放。

## 操作

- `WASD` / 方向键：移动
- `Shift`：奔跑（消耗体力）
- `C`：切换蹲伏
- `E`：按一次开始搜索容器 / 按住拉闸或撤离
- `Tab`：打开 / 关闭背包
- 鼠标点击 / `Space`：投掷罐头
- 红狼 `X`：动力外骨骼
- 红狼 `G`：烟幕弹
- 红狼 `V`：三联装手炮
- `Esc`：暂停

### 手机操作

- 左侧摇杆：移动；摇杆推到外圈自动奔跑
- 右侧“投掷”：自动瞄准射程内最近的可见敌人
- 右侧“搜索”：按住搜索、拉闸或撤离
- “背包”与“蹲伏”：打开物资界面、切换蹲伏
- 画面右上角：红狼的强化、烟幕和手炮快捷按钮，以及暂停按钮

触屏按钮使用 Pointer Events，同一套输入可覆盖 Android、iOS 和桌面触屏设备。切到后台时会自动暂停，避免小游戏被系统挂起后继续计时。

## 微信 / 抖音小游戏迁移

`platform.js` 是浏览器、微信小游戏 `wx` 与抖音小游戏 `tt` 的平台桥，目前统一了前后台生命周期、轻重震动和本地最高带出记录。浏览器版仍可独立运行。

当前项目依赖 DOM、CSS 和 HTML 按钮，因此不能直接把目录上传为原生小游戏包。正式发布前建议保留 `game.js` 中的纯玩法状态与 Canvas 绘制，将 HUD/背包改为 Canvas UI 或接入小游戏 UI 框架，再补齐以下平台工程能力：

1. 创建微信与抖音各自的小游戏工程入口、配置文件和分包策略。
2. 将 `platform.js` 扩展为登录、云存档、分享、激励视频广告和排行榜接口。
3. 把字体与音效改为本地资源并做首包体积、低端机帧率和内存测试。
4. 准备隐私协议、用户信息授权说明、版号/软著及平台审核素材。

角色名称与技能参考现有商业游戏。若计划公开或商业发布，应在提交审核前替换为原创角色、名称、世界观和视觉资产，避免知识产权风险。

## 搜索与物资

- 地图内有旧帆布包、工具箱、回收桶、医疗箱、储物柜、军用物资箱和保险箱，共 4 个容器等级。
- 靠近容器后按一次 `E` 开始搜索。移动、离开容器或受击会打断搜索；高级容器耗时更久，但掉落更多。
- 物资分为普通、优良、稀有、史诗、传说和至臻 6 个等级。高级容器会显著提高高等级物资的出现概率。
- 容器开启后物资会散落在地面，不会自动进入背包。按 `Tab` 打开背包，左侧显示已拾取物资，右侧显示角色附近的地面物资。
- 将右侧物资拖到左侧可拾取；将左侧物资拖到右侧可丢弃。也可以双击物资完成同样操作。单击道具可在检查器查看类别、价值与重量并使用快捷操作；背包有 10 个格位与 12kg 负重限制。
- 背包打开时冻结战斗、计时和技能冷却；再次按 `Tab`、`Esc` 或关闭按钮返回行动。触屏可用“包”按钮打开，轻点物资后使用检查器按钮转移。
- 拾取失败时物资留在原地；丢弃的物资可以再次拾回。地面物资不会直接计入撤离估值。

| 容器等级 | 容器种类 | 每次掉落 | 单件物资为史诗或以上的概率 |
| --- | --- | --- | --- |
| T1 | 旧帆布包、维修工具箱 | 1–2 件 | 3% |
| T2 | 加固回收桶、医疗补给箱 | 2–3 件 | 9% |
| T3 | 战术储物柜、军用物资箱 | 3–4 件 | 32% |
| T4 | 高密保险箱 | 4–5 件 | 65% |

上述概率按每件掉落独立抽取；至臻物资在 T1–T4 容器中的单件概率依次为 0.05%、0.2%、1%、5%。

角色名称与技能命名参考《三角洲行动》公开资料；本项目为非商业同人玩法原型，不包含原作美术素材。

## 干员与技能

三个干员均可选择并进入游戏，使用不同颜色的角色。此次完整实装红狼的三项主动技能，威龙和蜂医展示官方技能资料，其专属技能未接入。

| 按键 | 技能 | 本小游戏的效果 | 冷却 |
| --- | --- | --- | --- |
| X | 动力外骨骼 | 持续 8 秒，移动速度提高 45%，可与 Shift 的 1.65 倍奔跑叠加；击败敌人延长 1 秒（最多 10 秒） | 25 秒 |
| G | 战术型烟雾弹 | 向鼠标方向投掷，落地后生成持续 8 秒的烟幕，遮挡敌人视线与追踪 | 12 秒 |
| V | 三联装手炮 | 沿瞄准方向间隔 0.14 秒发射三枚高爆弹，命中或飞行结束后爆炸，中心伤害更高，墙体阻隔爆炸 | 7 秒 |

时长、速度、伤害和冷却是本小游戏的平衡参数，不是原作精确数值。没有鼠标瞄准时，技能沿角色朝向释放。

玩家使用显式有限状态机：`IDLE / WALK / SPRINT / CROUCH / HIT / DEAD / EXTRACTED`。C 为切换蹲伏；蹲伏优先于奔跑，速度为行走的 52%，敌人的初次侦测半径从 320 缩短至 175。奔跑消耗体力，耗尽后恢复至 25 才可再次奔跑，避免状态抖动。受击有短暂硬直与独立伤害保护。

官方角色资料来源：[《三角洲行动》官方干员介绍](https://df.qq.com/cp/a20240920pcfirst/lenovo.html)，核对日期：2026-10-16。

- 威龙：虎蹲炮、动力推进、磁吸炸弹；特长为动能辅助系统。
- 红狼：动力外骨骼、三联装手炮、战术型烟雾弹；特长为战术滑铲。
- 蜂医：激素枪、烟幕、蜂巢科技烟雾弹；特长为高效救援。

## 撤离规则

1. 搜集至少 `¥1200` 的潮物，取得撤离资格。
2. 前往地图右下角撤离区外侧总闸，持续按住 `E` 1.6 秒拉闸；受击会打断拉闸。
3. 拉闸会触发警报，闸门供电 8 秒，其间清洁队增援速度和数量上限都会提高。
4. 闸门开启后进入撤离区，持续按住 `E` 2.4 秒呼叫接应；松开按键时进度回退，受击则清空进度。
